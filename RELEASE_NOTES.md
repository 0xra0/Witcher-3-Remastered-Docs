# Official documentation snapshot — 13 October 2026 (game patch 5.01)

This release contains an offline copy of public official The Witcher 3: Wild Hunt — Remastered and REDkit documentation, collected on 13 October 2026. It includes the official game patch 5.01 note, four official mod.io guides, and CD PROJEKT RED's public REDkit documentation space. No GitHub repositories or community mod downloads are included.

## Assets

- `witcher3_official_5_01_docs.zip`: compact six-page reference set (patch note, REDkit 5.x changelog, four Remastered guides).
- `witcher3_official_full_docs.zip.part-aa` and `.part-ab`: the complete offline ZIP split into two pieces to fit GitHub's per-asset size limit. Download both and concatenate in the listed order; see README for Linux/macOS and PowerShell commands.
- `witcher3_offline_scraper_v9.zip`: the scripts and official-only source configuration used to build the archive.
- `SHA256SUMS`: hashes for release assets and the reconstructed full ZIP.

The full archive has 90 public pages, 1,128 saved Confluence attachments, and 14 official-guide-linked videos. Verification recorded zero integrity errors. The source API also listed 38 zero-byte broken attachments; these are recorded as unavailable. Older REDkit pages may predate patch 5.01; consult the current official patch notes for version-specific behavior. This is an independent archive, not an official CD PROJEKT RED release.
